Definitions and comparison choices

Released from rest at positive φ₀ at t = 0. The angle is measured from the downward vertical; the positive tangent points toward increasing φ. Gravity is fixed at g = 9.81 m/s². No damping.

dφ/dt = u/L   and   du/dt = −g sin φ.

Match period and each peak: the reference uses the nonlinear period T and independently matches the peak magnitude in each plot. Position uses A cos(2πt/T), velocity uses −U sin(2πt/T), speed uses U |sin(2πt/T)|, and g sin φ uses B cos(2πt/T). These separate shape references are not a single dynamically consistent solution. This removes period drift and amplitude mismatch so waveform differences stand out.

Small-angle prediction: φ = φ₀ cos(ω₀t), u = −Lφ₀ω₀ sin(ω₀t), and g sin φ ≈ gφ₀ cos(ω₀t), where ω₀ = √(g/L). The horizontal reference uses x ≈ Lφ. Both timing and amplitude differences are visible.

Speed is nonnegative, so its reference is the absolute value of a sine, not a signed sine. Use the signed-velocity panel to compare ordinary sinusoidal waveforms. Arc displacement and angle have identical normalized shapes; horizontal position need not.

The nonlinear curves are computed by fourth-order Runge–Kutta integration, with 2,400 steps per exact period. The period is T = 4K(sin²(φ₀/2))√(L/g), with K using the parameter convention. Two complete oscillations are shown.
